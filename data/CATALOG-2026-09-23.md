# September 23 catalog import

Requested window: June 23–September 23, 2026, plus upcoming releases. When an exact release date is unavailable, the requested exception permits sneakers shown in official NEW ARRIVAL lists or on the first page of an official category sorted newest first.

This import adds 1,571 products from 44 brands and preserves all 515 previous seed records. Thirteen entries have an official coming-soon or preorder indication, including Nike's announced October 1 Kobe A.D. Protro release. Product publication timestamps are retained only as source metadata, never converted into release dates. Images were fetched and decoded to verify dimensions; image-derived HEX values are approximations.

The import is **not an exhaustive completion of all 116 brands**. The audit identifies every requested brand, source attempts and added counts. A brand with no additions is marked as requiring review rather than having no new sneakers. Some catalogs block access, render product data only after interaction, or provide insufficient new-arrival evidence. Regional catalogs and every pagination path have not all been exhausted.

- `catalog-2026-09-23.json`: normalized additions with item-level official source links and evidence type.
- `catalog-audit-2026-09-23.json`: coverage and limitations for all 116 requested brands.
- `../public/catalog-coverage.html`: public, readable coverage report.

Run `node scripts/import_catalog.mjs` to embed the additions idempotently and `node scripts/validate_catalog.mjs` to validate the normalized records and generated JavaScript. The existing scheduled updater remains available. Verified import records explicitly include fall/winter sneakers; the legacy season exclusions continue to apply to older unverified ingestion paths.

Browser verification used headless Edge: retained seed records, visibility of every new item, Rick Owens/Celine/Nike filters, upcoming labels, all 116 audit rows, and browser-storage quota fallback. The initial catalog is no longer duplicated in localStorage, and quota errors fall back to memory for that browser session.
