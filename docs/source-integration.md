# 공개 출처 수집과 표시

## 화면의 출처 이름

공개 `catalog.sourceDirectory`는 `magazine`, `newsletter`, `sns`, `ecommerce`별로 다음을 구분한다.

- `configured`: 검토하여 등록한 수집 대상의 `id`, `name`, `url`, `method`. 실제 상품이 언급되었다는 뜻은 아니다.
- `observed`: 현재 공개 상품의 유효한 원문 근거에서 집계한 출처와 상품 수. 생성기는 최종 상품 목록에서 다시 계산한다.
- `checkedAt`: 수집 실행 시각.
- `checks`: 해당 실행에서 실제 응답한 공개 피드·순위 자료의 주소, 확인 시각, 항목 수, 일치 상품 수, SHA-256 본문 해시. 순위 자료는 국가·카테고리·기간·상위 100개 범위를 함께 기록한다. 원문 전체나 인증 정보는 포함하지 않는다.

상품별 근거에는 `publisherName`/`platformName`을 기록한다. 매거진의 이름 대신 막연한 “원문”으로 표시하거나, 확인되지 않은 플랫폼을 사용 중인 출처로 표시하지 않는다. 이 정보는 요청한 17개 엑셀 다운로드 열에 추가하지 않는다.

## 등록한 원문 경로

2026-09-28 공개 원문에서 직접 HTTP 200과 RSS 구조를 확인했다. 검색 API 키 없이 매주 각 피드를 한 번 읽고, 출시·상품 적합성 검사를 이미 통과한 모든 상품과 대조한다.

기사 검색도 기본값은 검증된 상품 전체다. 테스트나 명시적인 제한 실행에서만 `maxProducts`를 지정한다. 검색 인증 실패는 한 번 확인한 뒤 동일한 실패 요청을 반복하지 않으며, 공개 RSS·플랫폼 순위 수집은 계속한다.

| 매거진 | Sneaker Bar Detroit | https://sneakerbardetroit.com/feed/ |

| 뉴스레터 | The Dassler | https://thedassler.substack.com/feed |

GQ Germany, PAUSE, Sole Retriever는 기존의 기사 검색 대상으로 남는다. 별도의 RSS 정상 수집을 주장하지 않는다. PAUSE의 `/feed/`는 HTML 홈페이지로 이동해 RSS로 등록하지 않았다. Substack 전체를 하나의 뉴스레터 출처로 취급하지 않는다.

RSS 원문은 최근 30일 발행일, 같은 발행자 도메인의 기사 링크, 제목을 요구한다. 정확한 품번 또는 사전 검토한 모델·색상 별칭이 있어야 해당 상품의 근거가 된다. SKU 뒤에 다른 숫자가 이어지는 경우는 다른 품번으로 거절한다. 추천 상품 구역, 명시적 협찬·광고, 외부 복제 링크는 독립 기사 근거로 쓰지 않는다. 기사 발행일을 상품 출시일로 사용하지 않는다.

뉴스레터는 서로 다른 발행자 2개를 등록했다. The Sneaker Newsletter는 Nick Engvall의 매체이며, [The Dassler의 소개](https://thedassler.substack.com/about)는 Woody & Craig가 만드는 비공식 adidas 트레이너·스니커즈 뉴스레터라고 명시한다. 매거진을 뉴스레터로 재분류하지 않았다. The Dassler는 2026-09-28 확인 당시 최근 30일 공개 RSS 원문 3개(최신 9월 26일)가 있었다. 공개 피드와 공개 미리보기만 사용하며 유료 원문 접근을 시도하지 않는다.

서로 다른 발행자 2개 이상이라는 기존 뉴스레터 인기 기준은 유지한다. 한 원문의 언급은 출처 근거로 보존할 수 있지만 인기 판정과는 별개다. 실제 스니커즈 뉴스레터인 The Kicks You Wear도 확인했으나 최신 RSS가 2026년 1월이어서 이번 대상에는 추가하지 않았다.

## 이커머스 기준

### 무신사

- [무신사 슈즈 랭킹](https://www.musinsa.com/main/sneaker/ranking)의 공개 페이지가 제공하는 `client.musinsa.com/api/home/web/v5/pans/ranking/sections/256`을 사용한다.
- 대한민국, 실시간, 스니커즈(`103004`), 스포츠화(`103005`), 샌들/슬리퍼(`103003`) 각 상위 100개다.
- 플랫폼이 설명한 매출·조회수·후기수 복합 인기 순위다. 각 항목의 명시적 `image.rank`, 순위 목록 문맥, 카테고리, 브랜드, 정확한 품번을 함께 확인한다.
- 플랫폼 `updatedAt`을 순위 기준 날짜로 보존하고 별도로 수집 시각을 기록한다. 날짜가 없는 동적 자료는 수집 시점을 기준으로 명시하며 출시일을 추정하지 않는다.

### 29CM

- [29CM BEST](https://www.29cm.co.kr/store/best-items)의 공개 앱이 쓰는 `recommend-api.29cm.co.kr/api/v4/best/items`를 사용한다.
- 대한민국, `ONE_WEEK`(1주일), 여성슈즈(`270100100`)·남성슈즈(`274100100`) 각 상위 100개다.
- BEST 화면은 이 API의 원래 배열 순서에 `counter(list-number)`로 번호를 붙인다. 동일한 위치를 기록하며 “판매 순위”라고 부르지 않는다. 제외 품목을 제거한 뒤 순위를 다시 매기지 않는다.
- `frontCategoryInfo`, `frontBrandNameEng`, 상품명 속 정확한 품번을 확인한다. 별도 발행일이 없으므로 `dateBasis=observed-snapshot`과 실제 수집 시각을 기록한다.
- 여성슈즈 목록에 로퍼·힐 등이 있어도 이미 승인된 슈즈 카탈로그와 대조하므로 이 수집으로 그 상품이 공개 목록에 새로 추가되지 않는다.

기존 출시일·MLB/DISCOVERY 적합성 검사는 순위와 독립적이다. 랭킹에는 오래된 제품·재입고가 섞일 수 있으므로 순위만으로 신상품을 만들지 않는다.

## SNS

현재 검토 완료한 계정·원문 게시물 목록은 비어 있다. Instagram을 이미 수집하고 있다고 표시하지 않는다. 계정의 독립성·판매자 여부·브랜드 소유 여부뿐 아니라 `reviewedOriginalPosts`의 각 URL에 원본 확인일과 검토 근거가 있어야 원본 게시물로 인정한다. 계정 전체에 `originalPostsVerified=true`를 붙여 모든 게시물을 원본으로 간주하는 방식은 제거했다.

이전 게시물 5개/계정 3개 규칙은 폐지했다. SNS는 최근 달력상 3개월에 확인한 아이템별 검색량·해시태그 게시물량을 구분한다. 공식 상품·사진과 정확한 아이템 증빙이 필요하다. 미공개 수치는 null이며 조회량으로 검색량을 대체하지 않는다. 같은 플랫폼·지표·국가·기간 안에서만 비교한다. [공식 증빙 및 SNS 정책](social-metrics.md)을 따른다.

04:31:07 UTC에 상품 보강 후 다시 확인한 공개 스냅샷은 **45개(발매 완료 33개 / 발매 예정 12개)**, 영어 키워드 테마 21개다. 보존 원본은 2,360개, 검토 대기 2,315개, 검증된 만료 아카이브 대기 0개다. 실제 시트 쓰기는 실행하지 않았다. 이후 강제 주간 수집을 하면 숫자는 달라질 수 있다.

이때 6개 RSS와 5개 플랫폼 순위 구간이 모두 정상 응답했다. 새로 정확하게 일치하는 상품 근거는 0개였고, 별도 검증해 보존한 기사 근거 10개가 현재 상품에 연결된다. 실제 사용된 매거진은 Sneaker News, Sneaker Bar Detroit, GQ Germany, PAUSE, Sole Retriever다. 뉴스레터·이커머스는 등록된 수집 대상과 현재 상품의 확인된 언급을 구분한다.

### 첫 공개 피드 점검 기록

04:20:17 UTC 실행에서 최근 RSS 항목은 Sneaker Bar Detroit 25개, Hypebeast 20개, Highsnobiety 8개, Sneaker News 7개, The Sneaker Newsletter 5개였다. 무신사 3개·29CM 2개 순위 구간은 각각 100개를 정상 읽었다.

그때 공개 가능한 16개 상품과 정확히 일치한 새 근거는 0개였고 기존 근거 6개를 보존했다. 이 결과로 무신사·29CM 인기 상품을 임의로 채우지 않았다. 실행 결과는 내부 `logs/research/source-verification.json`에 있다. 피드와 순위는 시간에 따라 바뀌므로 이 수치는 수집 시점의 결과다.

첫 주간 수집에서는 기존 Jina 키가 HTTP 401로 거절되어 검색 발견 범위가 제한되었다. 이번 공개 RSS와 무신사·29CM 원문 경로는 별도 키 없이 작동한다. 원래 검색 경로의 인증 문제가 해결되었다고 주장하지 않으며, 등록한 모든 브랜드·상품이 시장 전체를 빠짐없이 대표한다고 주장하지 않는다.

현재 인기 순위는 실제 검색어·복합 인기·해시태그 원순위를 플랫폼별로 `1 / 원순위` 합산하여 계산한다. 같은 플랫폼의 동의어는 최고 순위 한 번만 기여하며, 원문 표기·원순위·종류·기간을 보존한다. `matchedProductCount`는 해당 조건에 맞는 유효 상품 수이며 인기 점수에 사용하지 않는다. 숫자 없는 공식 인기·매체 표현은 종합순위 없이 표시하고, 미래예측은 별도 목록으로 제공한다. 기존 21개 테마는 내부 매칭 분류로만 남긴다. 유효기간·집계·매칭의 현재 기준은 [키워드 집계 정책](keyword-ranking.md)을 따른다.

## 3개월 만료와 기존 기록

`curateCatalog`는 화면에 올라왔던 상품뿐 아니라 보존된 원본 전체를 다시 검사한다. 출시일·카테고리·적합성·검증 근거를 통과한 상품이 한국 날짜 기준 3개월보다 오래되면 공개 목록에서 제외하고 `data/archive-queue.json`에 넣는다. 경계 날짜는 포함한다. 검증 대기 중이던 원본도 나중에 검증되면 동일하게 처리된다.

“최근 3개월 상품 전량”은 검증된 적합 상품 전체를 뜻한다. 수량을 늘리려고 출시일을 모르는 기록을 최근 상품으로 만들지 않는다. 위 점검 시 원본 2,337개 중 공개 가능 16개, 검토 대기 2,321개, 검증된 만료 아카이브 대기 0개였다. 이후 수집 실행에서는 값이 바뀔 수 있다.

출시일 미확인·부적합 상품은 보존된 원본과 검토 목록에 남고, 임의의 날짜로 시트에 옮기지 않는다. 아카이브는 기존의 암호화 백업·중복 검사·추가 전용 쓰기·읽기 재검증을 거친다. 이 작업은 실제 시트에 행을 만들지 않았다.
