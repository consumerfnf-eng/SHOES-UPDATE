## 확인 범위와 제한

공식·리테일의 수집된 후보와 정확한 상품 증거를 대조한 결과다. 모든 국가·동적 재고 전체의 영구적인 무누락을 보장하는 의미는 아니다. Common Projects 공식 카탈로그에 연결할 수 없어 MR PORTER·Kith 실제 상품으로 보완했으며, 판매 확인일을 발매일로 만들지 않았다.

## 해결한 문제

- 제품 URL/제목의 추천 상품 오연결과 비신발 혼입 → 정확한 PDP·SKU·사진 결합 및 제외 근거 보존.
- SSENSE 카테고리 코드와 실제 모델 코드 혼동 → 모델·변형·리테일 ID를 분리.
- 같은 색 이름·비슷한 이미지 해시만으로 삭제 → 전체 코드와 검증된 동일 변형만 중복 처리.
- 최적화 후 리테일 이미지 경로 미갱신 → 공식·리테일·분석 저장소의 경로를 함께 갱신하고 빌드에서 SHA-256 검사.

1. 내부 Direct Upload 자동 배포: 프로젝트 범위 CI 자격 증명과 비공개 CATWALK 보존 저장소를 먼저 설계. 현재 GitHub 수집 커밋만으로 내부 배포가 갱신되지는 않는다.
2. 브랜드별 공식 총수·페이지 수·실패 목록을 운영 화면에 표시하고 누락 변화를 감시.
3. 코드·이름·사진 근거 및 수동 판정 이력을 검토하는 운영 화면.
4. 상품·컬러칩 초기 로딩 분할과 이미지 프레임 표준화.
