# SNS 인기 신상 운영안 · 2026-10-07

현재 `SNS 인기 신상` 탭과 상품별 지표 검증·표시 기능은 배포되어 있다. 검증된 제품별 지표는 0건이며, SNS 자동 수집 어댑터는 아직 연결되어 있지 않다. 탭 추가, 플랫폼 문서 확인, 실제 지표 수집 완료를 구분한다.

## 추천 수집 순서

1. 공식 New·New Arrivals 근거가 있고 사이트 게시 기간이 남은 모델만 후보로 만든다. 컬러·남녀 품번 수를 모델 인기로 중복 집계하지 않는다.
2. TikTok Creative Center에서 모델명·검토된 모델 별칭의 해시태그를 찾는다. 한국 중심으로 조사하고 글로벌 자료는 별도로 표시한다. `sneakers`·`balletcore` 같은 일반 주제는 스타일 동향이며 특정 제품의 인기 증거가 아니다. Speedcat 전체의 지표를 Speedcat Ballet 또는 새 컬러의 지표로 복제하지 않는다.
3. 원문에서 공개된 게시물 수·검색량의 종류, 측정 기간, 국가, 확인 시각, URL을 보존한다. 기간이 없는 누적 수치는 누적으로 표시한다. 조회수·좋아요·검색결과 개수를 검색량으로 바꾸지 않는다.
4. Instagram의 해당 모델 해시태그 원문을 확인해 잘못된 모델 매칭과 광고성 자료를 검토한다. API에서 받은 최근/인기 게시물 목록의 길이는 플랫폼 전체 게시물 총량이 아니므로 원문 검토 자료로만 쓴다.
5. 동일 플랫폼·국가·기간·지표끼리만 비교한다. 수집 표본 안에서의 순위를 시장 전체 순위로 표현하지 않는다. 전주 대비 변화는 같은 조건의 실제 이전 관측값이 있을 때부터 계산한다.
6. 지표 검증을 통과한 모델에만 인기 근거를 붙인다. 화면 사진은 공식 측면·45도 상품 사진을 사용하며 SNS 착장·전신 사진을 대표 사진으로 가져오지 않는다. 모델별 컬러칩과 상세 사진 전환은 일반 목록과 동일하다.

## 플랫폼별 가능한 작업과 연결 조건

| 출처 | 확인한 기능 | 운영 조건 |
| --- | --- | --- |
| TikTok Creative Center | 해시태그 검색, 업종·기간 필터, 추이·관련 영상·지역별 인기도 확인 | 공식 안내는 로그인을 전제로 한다. 접근 가능한 공개 원문 또는 승인된 자료를 우선 검토한다. 이번 조사에서 무인 수집용 공식 API 계약을 확인하지 못했으므로 자동 수집이 연결되었다고 표시하지 않는다. |
| Instagram Hashtag Search | 공개 해시태그의 최근·인기 미디어 조회 | Business 또는 Creator 계정, App Review, Instagram Public Content Access 및 instagram_basic 승인이 필요하다. 7일 동안 고유 해시태그 30개 한도가 있어 후보 모델을 우선 선정해야 한다. |

TikTok은 우선 원문 확인 후 구조화 자료를 가져오는 방식으로 시작하고, Instagram은 승인된 계정 연결 후 API를 붙이는 것이 현실적이다. 연결 전에는 현재처럼 검증 대기로 표시한다. 계정 비밀번호·브라우저 쿠키를 코드나 수집 파일에 저장하지 않는다.

가져올 데이터는 기존 `data/social-metric-evidence.json` 계약을 따른다. 상품 ID/브랜드/품번 또는 검증된 모델 식별자, 플랫폼, 검색어, 지표 종류·단위·값, 국가, 기간, 확인 시각, 원문 URL을 사용한다. 모델 지표를 색상마다 복제해 인기를 부풀리지 않는다. 원문과 정확한 모델 연결이 불분명한 기록은 게시하지 않는다.

- [Meta: Hashtag Search](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-facebook-login/hashtag-search) — 2026년 8월 17일 갱신 문서. 계정·앱 심사·권한과 7일/30개 제한, 최근·인기 미디어 엔드포인트 안내.

위 기준은 운영 제안이며, 실제 인기 수치가 확보되었다는 뜻은 아니다. 현재 공개 제품을 임의의 인기 예시로 채우지 않는다.
