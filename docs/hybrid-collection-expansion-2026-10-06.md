# 혼합형 스니커즈 수집 확대

## 후속 변경: grounds 제외

2026-10-06 사용자 요청으로 grounds를 공개 브랜드 목록과 자동 수집 대상에서 제외했다. 공개된 7개 컬러 상품(4개 모델)을 내려 현재 60개 브랜드, 68개 컬러 상품(44개 모델)을 표시한다. 기존 원본·출시 근거·사진과 Google Sheets 기록은 보존한다. 이전 기준의 수집 실행 37435631863은 시트 기록과 게시 단계 전에 취소했다.

아래 내용은 이 제외 요청 이전 수집 확대 작업의 기록이다.

## 최초 변경

- 기존 61개 브랜드를 모두 수집 대상으로 유지한다.
- 발레리나·메리제인·뮬 외에도 샌들·클로그·슬라이드·에스파드리유·피셔맨 형태에 스니커즈 구조가 결합된 상품을 검토한다. 공식 제품명이나 공식 설명에서 구조를 확인해야 한다. 구두·슬링백·힐·로퍼는 계속 제외한다.
- 서버 수집의 브랜드별 후보 10개 도달 시 중단, 최대 18개 보관 제한을 제거했다. 모든 설정된 공식 출처와 검색 경로를 시도한다.
- Dior 홍콩, Louis Vuitton 브라질, ALOHAS 미국, Melissa 미국, grounds 미국·일본 공식 경로를 추가했다.
- 기존 Reader와 직접 HTML이 실패하면 공개 페이지 렌더링 수집을 추가로 시도한다. Firecrawl의 자동 프록시를 사용하며, 서버 요청을 순차 실행하고 6.5초 간격·실행당 24회 제한을 둔다. 일시적 직접 HTML 오류는 기존 재시도 규칙을 따른다. 공급자 인증·한도 오류가 발생하면 해당 수집 경로를 중단한다.
- 기존 일요일 08:00 KST 상품·키워드 예약을 유지한다. SNS 로그인 연결은 별도 설정이 필요하다.

## 추가 상품

[grounds 공식 GRAFFITI 발표](https://grounds-fw.jp/blogs/news/graffiti)에서 모델과 색상을 대조한 **2026-09-26 일본 출시 7개 색상, 4개 모델**을 추가했다.

| 모델 | 색상 수 |
|---|---:|
| GRAFFITI 2046 | 3 |
| GRAFFITI 2046 BEENAWHILE | 1 |
| GRAFFITI NOA | 1 |
| GRAFFITI NOA BEENAWHILE | 2 |

기존 68개 색상에 추가해 75개 색상이다. 같은 모델은 한 카드와 색상칩으로 묶는다. 공식 원본 사진은 그대로 캐시하고 CSS로 확대·정렬한다. 제조사 품번을 확인하지 못한 Shopify 상품 ID는 `상품 ID`로 구분하며, 연결된 시트의 상품코드 칸에 제조사 품번인 것처럼 저장하지 않는다.

기존 원본 2,436개 상품의 모든 필드와 이전 전체 수집 정보를 그대로 보존했다. 만료 대기 3개 상품도 보존했다. 수동 추가를 전체 수집 완료로 기록하지 않았다. 이 수동 추가 과정에서 Google Sheets를 수정하지 않았다.

## 공개 기준과 남은 한계

수집한 후보는 출시일, 상품·색상 일치, 공식 상품 페이지, 공식 측면/45도 제품 사진 검증을 모두 통과해야 공개한다. 사진 검토가 필요한 새 후보를 자동 승인하지 않는다. 명시적 날짜가 없는 NEW ARRIVAL, 재입고, 검색 결과 날짜는 최근 출시로 취급하지 않는다.

요청한 전체 브랜드를 대상으로 수집 경로를 늘렸지만, 모든 사이트의 모든 상품을 빠짐없이 확보했다고 보장할 수는 없다. 사이트 차단, 렌더링 한도, 페이지 구조, 출시일 미공개, 사진 검토가 남을 수 있다. 특히 현재 대부분 브랜드의 새로운 대표 사진은 검토를 거쳐야 하며, 범용 자동 사진 심사 기능은 아직 없다.

## SNS 로그인과 매주 자동 수집

실제 연결 방식, 사용자 로그인 순서, 클라우드 프로필의 보관 위치·비용·만료 처리, 카드 선정 기준은 [SNS 주간 연결 안내](sns-weekly-setup.md)에 정리했다. 로그인된 Codex 브라우저와 GitHub 서버는 별개이며, 현재 SNS 수집 어댑터나 외부 로그인 프로필을 생성하지 않았다.
