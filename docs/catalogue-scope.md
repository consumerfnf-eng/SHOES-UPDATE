# Catalogue scope and identity

The brand registry is `config/site-brand-groups.json`: 62 LUX, 38 SPORTS and 16 CASUAL brands, in the requested order. `npm run build` regenerates the browser policy. McQueen aliases Alexander McQueen; the Toga Pulla and Toga Virilis lines remain separate. Unlisted non-LUX brands and explicit excluded brands cannot enter publication or scheduled brand collection.

The official-products view contains LUX products with exact brand-owned product and photograph evidence. An official assortment listing establishes availability, not a launch date. The inventory adapter reads Shopify until an empty page; short pages do not establish exhaustion, and repeated pages/page ceilings remain incomplete. Source coverage must stay explicit: reachable entries and a completed feed for one region do not prove worldwide or all-LUX completeness.

Retail publication requires a verified first release within three calendar months, bound to the exact brand, physical style and product URL. The `releaseEvidence` contract is shared by the browser and Python pipeline: `verified: true`, `kind: first-release`, `firstRelease: true`, an exact calendar `date`, an HTTPS source `url`, matching `productUrl`, `brand` and `style`, and authority `brand-official` or `retailer-explicit-first-release`. Restocks, reissues and future releases are excluded. Upload dates, listing dates, new-sort placement, first discovery, season codes and current stock never establish release. Raw excluded retail records remain in `data/retail-source.json`, outside site delivery.

A Shopify size ID is not a physical colour ID. Feed assembly collapses sizes and splits colour/material options, binding each to its assigned photograph. URL normalization removes size-oriented `variant` parameters, so URL deduplication must also consider the separate physical option ID. Product/model/physical-variant reviews bind to the exact brand, code, URL and original image. Full reviewed variant identity may consolidate alternative photographs and gender size runs; the retained record keeps alternative URLs, earliest history and the preferred women's representative. A shared retailer category-code prefix never proves model identity.

Colour corrections retain their original source labels and bind to exact photos. Public colour/model repairs must also refresh keyword tags and search concepts. Explicit possessive headline brands in newsletters outrank a designer's former employer. Source-specific sidebars hide brands without results in that source. Ranking boards retain original ranks while excluding brands outside the registry.

Card renditions are immutable, content-addressed WebP files bounded at 512 × 640. Reviewed crop bounds apply to cards; detail and JPG export retain full original assets. The `catalog-ui-v3` wire format preserves all fields exactly and decodes older formats. Build checks round-trip equality and every delivered photo checksum. Optional model-category data does not delay the first grid.

Run `npm test`, `python -m unittest discover -s tests -p 'test_*.py'`, `npm run test:ui`, and `npm run build`. The release audit in `data/site-scope-release-audit.json` records source preservation, scope changes, duplicate reasons, measured byte savings and coverage limits. Private queues and coverage diagnostics are excluded from public delivery. See `docs/internal-deployment.md` for authenticated direct upload to the internal project; premium CATWALK files remain ignored by Git.
