# SHOES TREND KEYWORD 표시와 원본 순위

## 현재 화면: 스타일 종합 목록 (2026-10-06)

첨부 대시보드의 번호·한글 해시태그·영문 설명·지표 구조를 사용합니다. 고정 점수나 순위 변동 화살표는 복사하지 않습니다. 아래의 원본 검색 순위 데이터는 보존하며, 화면에는 `verified-style-board-v1`으로 집계한 스타일만 표시합니다.

- 기사: 최근 달력상 3개월의 독립 스니커즈 트렌드 본문. 확인 후 7일 이내여야 합니다. Who What Wear와 Harper’s Bazaar의 지정 원문을 포함하며 같은 매체의 신규 트렌드 기사도 매주 탐색합니다. 메뉴·상품 위젯·관련 기사·구두 섹션은 제외합니다.
- 이커머스: 무신사 스니커즈·스포츠화, 29CM 여성·남성 BEST에서 스니커즈 하위 분류만 추립니다. 상품명에 명시된 스타일·소재·색상을 사용합니다. 무신사·29CM 검색어 원순위도 동일한 스타일 개념이면 반영합니다. 브랜드 인기나 전체 신발 검색어는 스타일 순위로 바꾸지 않습니다.
- 캘린더: Sole Retriever의 이름·품번·발매일이 연결된 항목 중 확인일 전후 30일. 공개 Reader를 사용하며 날짜순 배열을 인기순위로 취급하지 않습니다. 차단되면 마지막으로 검증한 7일 이내 근거만 원래 확인일 그대로 유지합니다.
- 순서: 서로 다른 출처 수 → 중복 제거 기사 수 → 플랫폼별 최상 상품/검색 원순위의 역수 합 → 발매 건수 → 고정 ID. 화면의 `신호`는 서로 다른 출처 수입니다. 상품 수·판매량·검색량으로 대체하지 않습니다.
- 한글 표제와 영문 설명은 같은 주제를 가리킵니다. 한영 동의어로 현재 공개된 최근 3개월 출시 스니커즈 전체와 연결합니다. 스타일은 확인되지만 해당 신상품이 없으면 0개로 남깁니다.
- 상품·키워드는 일요일 08:00 KST 주간 작업에서 갱신합니다. 일일 만료 처리는 수집을 하지 않습니다. 키워드 영역에는 원문 링크를 표시하지 않으며 감사용 URL·확인일·원순위·유형은 데이터에 보존합니다.

## 원본 검색·예측 데이터의 집계 규칙


검색어·제목·태그의 원문 표기를 유지합니다. 이번 주 목록은 스타일·실루엣·소재·색상·구조·용도만 다루고 브랜드·모델·캐릭터 고유명과 일반 신발/운동화만 있는 표현은 제외합니다. 출력 keywordType은 style, 방법은 verified-style-source-rank-v2입니다. 기존 21개 주제는 상품 매칭을 돕는 내부 분류이며, 실제 인기순위가 없는 주제를 순위 목록에 채우지 않습니다.

## 현재 인기 합산

| 출처 유형 | 원래 수치 | 합산 처리 |
| --- | --- | --- |
| `search-rank` | 플랫폼의 실제 검색어 순위 | `1 / 원순위` |
| `composite-rank` | 최신 보고서의 실제 스타일 관련 복합 인기 순위(브랜드 순위 제외) | `1 / 원순위` |
| `hashtag-rank` | 지정 국가·기간의 실제 해시태그 순위 | `1 / 원순위` |
| `search-popular` | 공식 인기검색어 목록, 순위 미공개 | 점수 없음 |
| `editorial-keyword` | 최근 원문 제목·소제목의 명시적 슈즈 스타일 트렌드 | 점수 없음 |

플랫폼별 최신 유효 스냅샷 한 개만 사용합니다. 같은 뜻의 검색어가 한 플랫폼에 여러 번 있으면 가장 높은 원순위 하나만 점수에 기여합니다. 다른 표기와 원순위는 `sourceRanks`에 모두 남깁니다. 플랫폼 가중치는 같습니다.

합계가 같으면 출처 수, 가장 높은 원순위, 안정적인 키워드 ID 순으로 정렬합니다. 숫자 근거 없이 공식 인기 표현만 있는 항목은 종합순위를 만들지 않고 목록 후단에 표시합니다. 의류·가구 등 제외어를 걸러도 원플랫폼의 순위 번호는 바꾸지 않습니다.

이 값은 **이번 주 수집한 공개 인기순위의 합산**입니다. 공개되지 않은 7일 검색량이나 동일한 종류의 측정치를 뜻하지 않습니다. 각 원문 옆에 출처 종류·실제 집계기간·지역·확인시각을 표시합니다.

### 유효기간

- 현재 인기: 실제 확인시각 `capturedAt`에서 168시간 이내.
- 기사·뉴스레터: 위 조건과 함께 원문 게시시각 `publishedAt`은 30일 이내. 이번 주는 갱신 주기이며 기사 발행 주간을 뜻하지 않습니다.
- 분기·기간 보고서: 최신 기간임을 확인해야 하며 `reportId`, `periodStart`/`periodEnd`, `validUntil`, `validityBasis`를 보존합니다. 원문을 다시 읽었다는 이유만으로 지난 보고서를 무기한 연장하지 않습니다.
- 일일 기한 점검과 브라우저도 만료된 근거를 인기순위에 쓰지 않습니다. 접근 실패를 0위나 임의의 순위로 대체하지 않습니다.

## 미래예측

`forecast-keyword`는 `forecastKeywords`에 별도로 표시하며 현재 인기 점수·출처 수에 섞지 않습니다. 미래 시즌, 원문 게시일, 원문 확인일을 구분합니다.

S/S 2027 색상 전망은 **운영 정책상 2027-08-31 한국시간까지** 유효합니다. 이 날짜는 출처가 발표한 종료일이 아닙니다. 일반적인 Blue를 Luminous Blue로 간주하지 않습니다. 전체 색명 또는 명시적으로 검토한 음역이 해당 상품의 색상에 있어야 매칭합니다.

## 한영 상품 매칭

`config/search-term-dictionary.json`은 검토 가능한 동의어·브랜드·모델·제외어 사전입니다. 브랜드·모델 사전은 상품 검색에 유지하고 이번 주 스타일 목록에서는 제외합니다. 대소문자, 띄어쓰기, 명시된 단복수와 한영 동의어만 정규화합니다. 원래 보이는 검색어는 바꾸지 않습니다.

- `브라운 스니커즈`: 브라운 계열 색상과 스니커즈 품목이 모두 맞아야 합니다.
- `뉴발란스530`: New Balance의 530 모델만 매칭합니다. 다른 New Balance 상품으로 넓히지 않습니다.
- `스피드캣`: PUMA Speedcat만 매칭합니다. 다른 얇은 밑창 상품은 포함하지 않습니다.
- 공식 확인된 상품명에 `Cecilie Bahnsen × ASICS`처럼 협업 관계가 명시되면 두 브랜드 키워드에 모두 연결합니다. 원래 주 브랜드와 다운로드 값은 유지하며, 설명의 추천·영감 언급이나 기업 계열 관계로 확장하지 않습니다.
- 검토되지 않은 낱말은 상품명·품번 등 문자 그대로 일치해야 합니다. 기사에 다른 색상이 함께 언급되어도 그 색상을 현재 상품에 붙이지 않습니다.

키워드 클릭은 유효한 출시 완료·발매 예정 상품 전체에서 찾습니다. 인기 원문에 직접 등장한 상품으로 제한하지 않으며, 정확히 맞는 상품이 없으면 0개로 표시합니다.

## 실행

매주 전체 수집은 상품 검증과 키워드 수집을 함께 수행합니다. 키워드만 갱신할 때는 `npm run keywords`를 실행합니다. 이 명령은 상품 원본·상품 출처 신호·마지막 전체 수집시각을 보존하고 키워드 근거와 공개본만 갱신합니다. Google Sheets 쓰기나 상품 전체 재수집은 호출하지 않습니다.
